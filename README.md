# gk-video-engine

Public. The renderer. One engine, many channels — no channel name appears anywhere in this repo.
The channel arrives as an input at run time, read from gk-control.

| folder | job |
|---|---|
| `src/components/` | the visual building blocks |
| `src/scenes/` | the beat templates, hook to CTA |
| `scripts/` | voice, capture, audio, thumbnail, audit |
| `public/` | bgm, fonts, assets |
